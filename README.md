# Análisis partido fútbol
Análisis de un partido de fútbol como un sistema biológico

Este proyecto analiza un partido de fútbol como si fuera un sistema biológico complejo. Los jugadores se modelan como nodos y los pases como flujos de información, de forma similar a una red metabólica, con el objetivo de entender cómo circula el balón y qué jugadores son estructuralmente clave para el sistema.

A partir de datos reales de eventos de partido, se construye una red de pases dirigida y ponderada. Sobre esta red se aplican métricas de análisis de redes, como centralidad y eficiencia global, para identificar cuellos de botella, nodos esenciales y vulnerabilidades del juego.
Además, se realiza un análisis de robustez inspirado en la biología de sistemas, en el que se simula la eliminación de jugadores para observar cómo se degrada la eficiencia del sistema. Los resultados permiten detectar jugadores cuya ausencia provoca un colapso estructural del juego.

Finalmente, los resultados se interpretan mediante inteligencia artificial generativa, que transforma métricas complejas en diagnósticos claros y comprensibles, acercando el análisis científico al contexto táctico del fútbol.
Este proyecto demuestra cómo herramientas de bioinformática, análisis de redes e IA pueden aplicarse al análisis avanzado del fútbol desde una perspectiva innovadora y explicativa.
